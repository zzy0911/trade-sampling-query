“四下”贸易抽样调查数据查询 v0.1.1
=====================================

适用系统：Windows 7 SP1 / Windows 8.1 / Windows 10 / Windows 11
请根据系统位数下载 x64（64 位）或 x86（32 位）压缩包。
浏览器请使用 Chrome、Edge 或 Firefox，不支持 Internet Explorer。

一、开始使用
1. 请先把整个 ZIP 压缩包解压到一个普通文件夹，不要直接在压缩包内运行。
2. 双击“TradeQuery.exe”。
3. 稍候片刻，系统会自动打开浏览器并进入 http://127.0.0.1:8000/ 。
4. 使用期间请保持黑色运行窗口开启；关闭窗口即停止服务。

二、管理员登录
默认账号：admin
默认密码：admin123

首次正式使用前，请双击“change-admin-password.cmd”设置新密码。新密码至少 10 个字符。

三、数据位置与升级
首次运行后，程序旁会自动生成 data 文件夹。数据库和上传的 Excel 原文件都保存在这里。
升级时，请先关闭程序并备份 data 文件夹，再把 data 文件夹复制到新版程序目录中。
发布包不包含任何业务数据。

四、常见问题
1. 浏览器没有自动打开：手动访问 http://127.0.0.1:8000/ 。
2. Windows 提示是否允许网络访问：仅本机使用时可取消；需要局域网共享时才允许专用网络访问。
3. 端口被占用：先关闭旧的程序运行窗口，再重新启动。
